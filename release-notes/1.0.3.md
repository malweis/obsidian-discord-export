## New

- **Export selection**: highlight some text and export just that, from the command palette or by right-clicking it (#1)

## Fixes

- Paragraphs longer than the character limit now get split at a sentence instead of overflowing
- Headings, lists and quotes don't get indented anymore so Discord actually renders them. If you want the old behaviour there's a new "Indent Markdown lines" setting
- Ignore blocks `{...}` don't leave stray spaces or blank lines behind anymore
- Tags with accents like `#canción` get stripped like the rest
- "Copied" marks reset when you switch mode or limit
